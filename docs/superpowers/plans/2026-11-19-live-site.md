# Live Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** after each successful check, `serve` (on `main`) builds the snapshot and replaces `gh-pages` with it; the pages use the real clock while the data is fresh.

**Architecture:** the snapshot gets versioned paths (`data/<id>/`, `static/<hash>/`, previous version kept) so the fixed 10-minute Pages cache never mixes files. The snapshot command's body moves into a reusable `take()`. A new `publish` module gates on branch and clean tree, then commits one parentless commit and force-pushes with lease through an injectable git runner. `_run_once` calls it between alerts and street suggestions, only after a successful check.

**Tech Stack:** Python 3.12+, stdlib `subprocess`/`hashlib`, git CLI, vanilla JS (`node --test`), pytest.

**Spec:** `docs/superpowers/specs/2026-11-19-live-site-design.md`

## Global Constraints

- Off by default: publishing only with `PUBLISH_SITE=1` (env or `.env`); target `PUBLISH_DIR`, default `<repo root>/site`, must be a git worktree on branch `gh-pages`.
- Publish only when the run checked and the check succeeded; order `check → alerts → publish → street suggestions`.
- Branch must be `main` both when `serve` started and at publish time; `git status --porcelain --untracked-files=no -- src/outages` must be empty.
- Git runs with `GIT_TERMINAL_PROMPT=0` and a 120 s timeout. No test runs `git push` against a real remote (a local bare repo in `tmp_path` is allowed).
- Admin note keys: `publish:skip:branch:<YYYY-MM-DD>`, `publish:skip:dirty:<YYYY-MM-DD>`, `publish:fail:<YYYY-MM-DD>` (Manila date), at most one per key; `PUBLISH_SITE` off sends nothing.
- Snapshot `FORMAT = 2`; `snapshot.json` gains `"data": "data/<id>/"`, `"static": "static/<hash>/"`, `"fresh_for_h": 15` (from `STALE_CHECK_H`). `<id>` = `taken_at` in Manila as `%Y%m%dT%H%M%S`; `<hash>` = first 10 hex chars of SHA-256 over the static files.
- Copy (exact): fresh credits `Updated <label> (Manila) from ` + link "VECO's advisories" + `; code: ` … ; old banner `Last updated <label> (Manila) and may be out of date. For current schedules see ` + link "VECO's advisories" + `.` — `<label>` is `snapshotLabel(last_check_at)`.
- No new dependencies. Live mode (`serve`'s map) unchanged. Offline tests; nothing touches GitHub, VECO or Telegram.
- Commits: conventional with scope, no AI attribution lines.

## Review Focus

1. **The remote moved** (an earlier push half-failed, or a hand push): the lease must refuse, local `gh-pages` must stay put, one `publish:fail` note. → Task 4, `test_push_refused_when_remote_moved` (real bare repo).
2. **`site/` missing or on another branch:** fail before writing anything, one `publish:fail` note. → Task 4, `test_publish_fails_when_site_not_gh_pages`.
3. **A page from the previous publish still loading:** after publish N, folders of N−1 must exist; after N+1, N−1's are gone. → Task 1, `test_write_keeps_previous_version_only`.
4. **First publish over today's format-1 site:** legacy `weeks/`, `stats/`, `boundaries.geojson`, `static/js|vendor|*.css` kept on that publish, removed on the next. → Task 1, `test_legacy_layout_kept_once`.
5. **`last_check_at` missing, malformed, or in the visitor's future:** missing/malformed → old (pinned); in the future (visitor clock behind) → fresh. → Task 2, `isFresh` cases.
