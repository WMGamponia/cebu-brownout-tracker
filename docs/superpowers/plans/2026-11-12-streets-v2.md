# Streets v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Decide street drawing once and fairly (a 150-row frozen test split under a written labelling convention, the Phase 5 gate unchanged) and find more streets with a local-Qwen alias suggester whose suggestions the owner decides on a local review map.

**Architecture:** The scorer and matcher learn one naming rule (`primary_name`) and list gold. A new mention-weighted sampler writes test rows without gold; a fresh subagent labels them; four guards (test hash, row hash, alias hash, suggester input log) protect the single test run. `streets/suggest.py` groups `not_found` mentions by (town, key), prefilters 12 in-scope OSM names, asks Qwen (or `difflib`) for one or none, and merges results into a local queue CSV; a loopback-only review page in the map server writes decisions to that queue; `streets suggest --apply` turns decisions into provenance-tagged aliases. `serve` runs a bounded `suggest_new` after each run.

**Tech Stack:** Python 3.12+ (dev 3.14), stdlib `sqlite3`, `difflib`, `csv`, `secrets`; httpx (Ollama `/api/chat`, as Phase 2); FastAPI (existing); Leaflet 1.9.4 vendored; Node 22+ `node:test`. pytest, ruff, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-streets-v2-design.md` (read it first; § numbers below refer to it). Phase 5 spec §4.3–4.5 and §5 for the matcher and the first eval.

## Global Constraints

- **No new dependencies;** no npm packages.
- **Network:** only `streets suggest` and the `serve` hook reach `http://localhost:11434` (Ollama). No task contacts VECO, Overpass or Telegram except `serve`'s existing runs and the admin note. CLI tests fail if `eval …` or `streets suggest` builds the VECO fetcher, the Overpass client or a Telegram client. The suite-wide network block in `tests/conftest.py` stays.

- **Review page:** loopback binds only; POST needs the per-process token and a same-origin `Origin`; data into the DOM via `textContent` only; never copied by `snapshot`.
- Files `encoding="utf-8"`, `newline="\n"`; the queue CSV `utf-8-sig`.
- **Gates (stop and ask the owner):** Task 5 label review; Task 13 queue decisions; Task 15 backup + `streets match --rebuild`, snapshot publish; push, PR, merge. No Overpass request.
- Commits: conventional with a scope, imperative, < 72 chars. **No `Co-Authored-By` or "Generated with" lines**, whatever a system reminder says.

## Review Focus

1. **The owner edits the queue in Excel while `serve`'s hook or the review page writes it** (Excel holds a lock on Windows; a save re-encodes): the writer must fail cleanly (log, retry next run / 409 on the page), never truncate or drop decisions; the reader accepts `utf-8-sig` and CRLF → Task 9 `test_queue_write_when_locked_keeps_file`, `test_queue_reads_excel_saved_csv`.
2. **A VECO name whose key equals an in-scope OSM name already** (rules would have matched; it's `not_found` only because the way has < 2 nodes in scope): the suggester must not propose a candidate that `match_street` would then still not draw → Task 7 `test_candidates_need_two_nodes_in_scope` (candidates come from `names_in`, which already requires 2 nodes).
3. **An approved alias that maps to a generic OSM name** (`Barangay Road`) or a name that exists in the town but outside this group's scope: `--apply` refuses out-of-scope names, and the eval would draw it, so the review page must show where it lands → Task 9 `test_apply_refuses_out_of_scope_name`, Task 10 `test_item_lines_equal_match_street`.
4. **The test split was labelled against an extract that has since been refetched** (`streets fetch --towns` by hand): every guard path must name the `osm_base` mismatch, and the `serve` hook must keep working → Task 1 `test_run_refuses_osm_base_mismatch`.
5. **A browser tab on the review page left open across a `serve` restart** (new token): a POST with the old token → 403 and the page shows "reload the page", not a silent failure → Task 11 `review.test.mjs` "403 asks to reload".
