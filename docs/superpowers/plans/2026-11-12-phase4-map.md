# Phase 4 Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `python -m outages map` (and a thread inside `serve`) serves a Leaflet map at `http://127.0.0.1:8765` showing which barangays may be without power for a chosen Manila day and hour, built from one read-only GeoJSON document, with unplaceable and stale outages called out rather than hidden.

**Architecture:** A committed `areas/boundaries.geojson` (derived from the pinned zip by `gazetteer`) holds every barangay polygon. A pure-ish `map.build` joins it with the outages in a `map.window` into one FeatureCollection (feature per barangay, top-level `outages` and `meta`). `map.app` is a FastAPI app with four GET routes over a per-request read-only connection; `map.server` runs it standalone or on a daemon thread in `serve`. The page is vanilla JS: a pure `timeline.js` (tested with `node --test`) and a Leaflet/DOM `map.js`.

**Tech Stack:** Python 3.12+ (dev 3.14), stdlib `sqlite3`, `json`, `zipfile`; FastAPI + uvicorn (new); httpx (TestClient); Leaflet 1.9.4 vendored; OSM tiles; Node 22 `node:test` (CI/dev only). pytest, ruff, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-phase4-map-design.md` (read it first; § numbers below refer to it).

## Global Constraints

- **New dependencies, approved:** `fastapi`, `uvicorn` (plain, not `[standard]`); Leaflet 1.9.4 vendored with its LICENSE. Nothing else; no npm packages.
- **No requests to visayanelectric.com, Telegram or tile servers in the build or CI.** `map` never builds the fetcher or a Telegram client; it gets a no-network CLI test like every offline command. The suite-wide network block in `tests/conftest.py` stays.
- **Read-only:** every map request opens `db.connect_ro`; the real DB's SHA-256 is unchanged after any map use.
- **Defaults:** `MAP_HOST = "127.0.0.1"`, `MAP_PORT = 8765`; a non-loopback host logs WARNING `map is reachable from your network; there is no login`. Running on `0.0.0.0` needs the owner's OK.
- **Times:** stored ISO `+08:00` strings pass through unchanged; `generated_at`/`last_check_at` converted to `+08:00`. JS never uses the browser's zone (`getHours`, `toLocaleString` without `timeZone`); Manila = epoch + 8 h read with UTC getters.
- **Copy fixed by the spec:** legend `Shaded: parts of these barangays may be affected.`; stale caveat `VECO updated this post and we couldn't read the update; this is from the earlier version.`; MECO tooltip `MECO area, not covered`; side list title `Not on the map (N)`; removed line `N outages no longer in VECO's post`; ambiguous `VECO lists <name> under <Town A> and <Town B>.`; old-data warning past **15 h**; attribution `Boundaries: faeldon/philippines-json-maps v1.1.1 (MIT), PSGC 3Q 2026` and `© OpenStreetMap contributors`.
- **Page safety:** data goes into the DOM only via `textContent`; links only via `setAttribute('href', …)` for URLs starting `https://www.visayanelectric.com/`. No `innerHTML` with data.
- Files read/written with `encoding="utf-8"`, `newline="\n"`. JSON with `ensure_ascii=False`.
- `data/` and `.env` are never committed. Commits: conventional with a scope (`feat(map): …`), imperative, under 72 chars. **No `Co-Authored-By` or "Generated with" lines.** No push, PR or merge without the owner's OK.
- Branch `phase4-map` (spec committed `5dd7362`). Never leave an empty `python -` heredoc; prefer the Edit tool on Windows; write Python with the Write tool.

## Review Focus

1. **Port 8765 already taken while `serve` starts** (a second `serve`, another app): uvicorn calls `sys.exit(1)` inside the thread. The thread must catch `SystemExit`, report once, and the 06:00/20:00 runs must still happen → Task 6 `test_map_thread_bind_failure_reports_and_scheduler_runs`.
2. **VECO text containing `<`, `&` or a URL that isn't VECO's**: the JSON carries text as stored (no HTML escaping server-side); the page inserts text only with `textContent` and drops non-VECO links → Task 4 `test_markup_in_text_passes_through_raw`, Task 7 `safe post url` tests.
3. **The browser's date differs from Manila's** (00:30 Manila is still the previous day in New York): the default tab and hour follow Manila → Task 7 `defaultSelection at 00:30 Manila under TZ=America/New_York`.
4. **The DB file doesn't exist yet** (map started before the first `backfill`): 503 with the "database not ready" body, and no empty file created → Task 5 `test_missing_db_503_creates_nothing`.
5. **One outage naming the same barangay twice** (two lines both say Tisa, or the ambiguous `Tayud` resolving into a code already listed): the barangay's `outage_ids` and the outage's `barangays` have no duplicates → Task 4 `test_duplicate_barangay_rows_deduplicated`.
